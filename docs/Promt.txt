

Quiero que desarrolles una aplicación completa de CONTROL HORARIO / FICHAJE DE TRABAJO en un único archivo HTML autocontenido, pensada principalmente para utilizarse desde el teléfono móvil, pero que también funcione perfectamente en ordenador.

IMPORTANTE:

* Entrégame un único archivo `index.html`.
* Debe contener dentro del propio archivo HTML todo el CSS y JavaScript necesario.
* No debe necesitar servidor, backend ni base de datos externa para funcionar.
* Los datos deben guardarse automáticamente en el dispositivo mediante `localStorage` o IndexedDB.
* La interfaz debe estar en español.
* Debe ser moderna, limpia, profesional, sencilla de usar y totalmente responsive para móvil.
* Debe funcionar bien tanto en Android como en iPhone usando el navegador.
* No quiero simplemente una maqueta visual: todas las funciones deben estar programadas y ser funcionales.

OBJETIVO PRINCIPAL

Quiero una aplicación personal para controlar:

1. Mis fichajes de entrada y salida.
2. Las horas normales trabajadas.
3. Las horas extra.
4. Los descansos.
5. El tiempo destinado a comer.
6. Los desplazamientos/trayectos en coche.
7. El histórico diario, semanal y mensual.
8. La exportación de toda la información a Excel.

4. HORAS EXTRA AUTOMÁTICAS
==========================

Esta función es especialmente importante.

Si mi jornada laboral configurada es de 8 horas y todavía NO he fichado salida cuando he terminado esas 8 horas efectivas, el sistema debe continuar contando automáticamente el tiempo adicional como HORAS EXTRA.

Ejemplo:

Entrada: 08:00
Trabajo normal necesario: 8 horas
Descansos descontados: 1 hora

A las 17:00 completo mis 8 horas efectivas.

Si sigo fichado:

17:15 → 00:15 de horas extra
17:30 → 00:30 de horas extra
18:00 → 01:00 de horas extra

Quiero que este contador de horas extra se actualice en tiempo real.

Mostrar claramente:

HORAS NORMALES
08:00

HORAS EXTRA
01:27

Las horas extra deben seguir aumentando hasta que pulse "Fichar salida".

IMPORTANTE:
El cálculo debe basarse en TIEMPO EFECTIVAMENTE TRABAJADO y no únicamente en la hora habitual de salida.

tiempoBruto - tiempoNoTrabajado

HORAS NORMALES =
mínimo entre tiempoEfectivo y jornadaConfigurada

HORAS EXTRA =
máximo entre 0 y (tiempoEfectivo - jornadaConfigurada)

Si está habilitada la opción correspondiente, incorpora correctamente el tiempo de trayectos según la configuración establecida.
